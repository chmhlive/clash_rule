# 🛠️ 个人自定义规则说明 (custom/)

此目录用于存放**你自己专属的 Clash 规则**。这里的规则具有**最高优先级**。

## 📌 使用方法

1. **新增个人独立规则**：
   在 `custom/` 目录下新增 `.yaml` 或 `.list` 文件（如 `MyNodeRules.yaml`），构建脚本会自动将其同步放入 `rules/` 目录中。

2. **追加至现有上游规则**：
   若你在 `custom/` 目录下放置了与上游同名的规则文件（例如 `Proxy.yaml` 或 `China.yaml`），脚本在处理时会将你的自定义内容自动**插入到对应规则的最顶部**，以确保你的自定义规则优先生效。

## 💡 示例结构
- `Direct.yaml`：存放你强制直连的域名/IP列表。
- `Proxy.yaml`：存放你强制代理的域名/IP列表。
